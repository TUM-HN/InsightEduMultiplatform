# Multiplatform App for Discord Bot Management & TUMDiscordBot-API
*Foundation based on [TUMDiscordBot](https://github.com/TUM-HN/TUMDiscordBot) and [InsightEdu](https://github.com/TUM-HN/InsightEdu).

A simplified tutor-bot system with:

- **MultiplatformApp**: A Multiplatform iOS/Android management interface for TUMDiscordBot-API, featuring UX for conducting content questions generation, AI-analysis, attendance tracking, surveys, feedback collection, role management, and real-time bot control via REST API.
- **TUMDiscordBot-API**: An educational Discord bot with REST API for programming course management, featuring ai-layer, generation of opened content questions, attendance tracking, surveys, feedback analysis and collection, and tutor support tools.

## Project Structure

```
.
|-- MultiplatformApp/        # Koltin Multiplatform iOS/Android client
`-- TUMDiscordBot-API/       # Flask API + Discord bot backend 
```

## Getting Started

1. Multiplatform Client:
   - Open `MultiplatformApp/README.md` and follow the setup steps outlined there.

2. API & Bot:
   - Open `TUMDiscordBot-API/README.md` and follow the setup steps outlined there.

Now you can configure the server IP and API keys in the Multiplatform app and interact with the tutor bot in Discord.
